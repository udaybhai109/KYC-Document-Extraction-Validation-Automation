# KYC Document Extraction & Validation Automation

## Overview

This project demonstrates an RPA workflow for automating parts of the KYC and client onboarding process using Automation Anywhere.

The workflow covers document data extraction, structured data handling, validation, OTP-based verification and presentation of the final KYC result.

## Internship Context

Developed and tested as part of my Digital Factory traineeship at Rogers Capital Technology Services Ltd.

## Workflow

Document Input
→ Data Extraction
→ Structured Data Processing
→ Field Validation
→ Expiry-Date Validation
→ KYC Status Decision
→ OTP Verification
→ Result / Onboarding Output

## Key Components

- Passport/document data extraction
- Excel and JSON data handling
- Date and expiry validation
- PASS / FAIL decision logic
- OTP-based verification
- Client onboarding form
- KYC result form
- Automation Anywhere bot and process orchestration

## Tools & Technologies

- Automation Anywhere
- RPA
- Excel

- PDF / document processing
- Browser automation
- Email / OTP automation
